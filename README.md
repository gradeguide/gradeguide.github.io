# gradeguide.github.io

This repository publishes the GradeGuide website at
<https://gradeguide.github.io/>. It holds only the deploy workflow; the site
itself is built from [gradeguide/gradeguide](https://github.com/gradeguide/gradeguide).

The workflow runs every hour and redeploys when the source's `main` branch
has changed. To deploy at once, open **Actions → Deploy → Run workflow**.
